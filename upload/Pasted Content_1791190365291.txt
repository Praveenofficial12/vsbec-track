Build a complete production-ready full-stack web application called:

"VSBEC Placement Management System"

The application is designed for a college placement/training department to manage students, company placement drives, attendance, rounds, selections, rejections, and placement analytics.

The main objective is:

1. Collect and maintain complete student placement profiles.
2. Allow students to register and maintain their academic/skill information.
3. Allow Admin/Staff to create and manage multiple company placement drives.
4. Track which students attended each company drive.
5. Track students through every recruitment round.
6. Update whether students are selected, rejected, on hold, or still in progress.
7. Provide powerful department-wise, year-wise, class-wise and company-wise analytics.
8. Help placement staff identify suitable students for upcoming companies.
9. Keep all student and placement data centralized and easy to analyze.
10. Make the system simple enough that staff can manage everything without technical knowledge.

Use a modern, professional, responsive UI suitable for a college placement department.

Recommended technology stack:

Frontend:
- React.js
- TypeScript
- Tailwind CSS
- Modern component-based architecture
- Responsive design
- Clean dashboard UI
- Cards, tables, charts, filters and modals

Backend:
- Supabase
- Supabase PostgreSQL
- Supabase Authentication
- Supabase Row Level Security
- Supabase Storage where required

Use proper authentication and authorization.

IMPORTANT:
Do not create a fake frontend-only application.
All important data must be stored in the database.
All student, company, drive, attendance, round and result information must persist after refresh/login/logout.
